# User stories

After SPEC.md is approved (Phase 0 exit), one story file will be added here per feature area — e.g. project workspace manager, agent registry, two-tier orchestration, approval gates, tool layer & permissions, providers, usage/cost dashboard, per-agent memory, skills, session view & screens, image input/vision routing.

Each file will carry stories as *"As a user, I ... so that ..."*, traced back to SPEC sections and forward to the acceptance criteria used in Tester reports.
