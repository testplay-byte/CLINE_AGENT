# Design Language — CLINE_AGENT Web UI

## Principles
1. **Modern & Clean** — Minimal, uncluttered, purposeful
2. **Animated** — Smooth transitions, meaningful motion
3. **Adaptive** — Works on any screen size
4. **Customizable** — Theme, colors, text size
5. **Accessible** — Keyboard navigable, screen reader friendly

## Typography
- Font: System font stack or Inter
- Scale: Modular scale (responsive)
- Line height: 1.5-1.7 for body text

## Animation Standards
- **Duration**: 150ms-300ms for micro-interactions, 300-500ms for transitions
- **Easing**: ease-out for enters, ease-in for exits, spring for interactive
- **Types**:
  - Fade in/out for appearance
  - Slide for directional transitions
  - Scale for interactive feedback (buttons)
  - Skeleton/shimmer for loading
  - Layout animations for list changes

## Component Patterns
- Cards with subtle shadows/borders
- Rounded corners (8-16px)
- Consistent spacing (4px grid)
- Hover effects on interactive elements
- Focus rings for accessibility

## Responsive Breakpoints
- Mobile: < 640px
- Tablet: 640-1024px
- Desktop: > 1024px
- Wide: > 1440px
