# UI Design Prompts

This directory contains detailed UI design prompts for each screen of the CLINE_AGENT application.
The user will use these prompts to generate UI designs, which will then be implemented by the agent.

## Process
1. Agent creates a detailed prompt for a screen → saved here
2. User generates UI design based on the prompt
3. User sends the design back to the agent
4. Agent implements the UI with logic, wiring, and state management
5. Repeat for next screen
